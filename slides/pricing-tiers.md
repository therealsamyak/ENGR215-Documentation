## Pricing Tiers

### D6 — Scout

- 6-drone swarm, ~1 km perimeter coverage
- Standard detection AI — sonar anomaly alerts on bridge command unit
- Manual remote override on up to 2 drones simultaneously
- Next-business-day drone replacement
- Email support

### D12 — Shield

- 12-drone swarm, ~2 km perimeter coverage
- Advanced detection AI — anomaly classification (debris vs UXO vs biological) with confidence scoring
- Manual remote override on all drones + AI-optimized search path planning
- Same-day drone replacement included
- Historical transit analytics and hazard density mapping
- Priority support

### Enterprise — Fleet

- Variable swarm size — scaled per vessel and route risk
- Full detection AI suite — real-time classification, predictive hazard modeling, and fleet-wide pattern recognition across all deployed vessels
- Multi-swarm coordination for ultra-large vessels or convoy operations
- ECDIS and bridge system integration — alerts pushed directly into existing navigation displays
- Dedicated account manager and 24/7 support
- Custom SLA with guaranteed replacement windows and uptime targets
- Co-branded insurer compliance reports for premium reduction documentation
